# 意图联合识别模块 Spec

## 背景

当前每轮用户输入走同一条处理链路:同一套工具定义、同一份 system prompt、
同一档执行策略。用户问"这个函数干什么"与要求"把 src/legacy 整个删掉",
系统的行为完全一致——包括后者不会得到任何额外提示。

本模块由一个独立配置的识别模型在主请求发起前对本轮输入做语义、工具、上下文、
安全四维联合识别,合并为一个结构化识别目标交给主 agent,由主 agent 依此执行。
其中安全维度捕获删除、清空、覆盖、重置等危险操作意图并给出标记与原因,
让主 agent 知道本轮请求存在风险、必要时向用户确认——这类判断不能交给主模型
自报,是本模块存在的核心理由。

本模块是一个纯输入输出单元:输入「当前用户输入 + 最近 3 轮历史」,输出
「识别目标结构体」。调用方如何使用识别目标不在本模块范围。

## 目标

- 由独立识别模型一次调用产出含四个维度的结构化识别目标。
- 危险操作意图被稳定捕获,包含不含危险字样但后果等价的表述。
- 识别目标结构稳定,消费方接口不随识别侧演进而变更。
- 识别失败、超时、结构不符统一降级,不阻断对话。
- 识别的延迟与 token 开销可观测,且可整体关闭。

## 假设与待定

- A1(假设):识别在用户提交后、主请求发起前完成,阻塞式,非流式。
- A2(假设):语义维度输出单一类别枚举。
- A3(假设):工具维度输出「允许使用的工具名集合」(上界),主 agent 在集合内自由选择。
- A4(假设):上下文维度输出「建议优先读取的路径模式列表」(提示),不限制实际可读范围。
- A5(假设):安全维度输出布尔危险标记 + 危险原因文字;是否向用户确认由主 agent 决定。
- A6(假设):识别由独立配置的识别模型承担,与主对话 provider 分离。
- A7(假设):识别失败/超时/结构不符时不重试,直接降级。
- A8(假设):降级时危险标记取 true(保守侧),工具集合取只读子集。
- A9(假设):每轮独立识别,不做会话级意图记忆或跨轮纠偏。
- A10(假设):识别输入为当前用户输入 + 最近 3 轮对话历史。
- A11(假设):识别结果在对话区显示一行摘要;危险标记为真时以可区分样式显示。
- A12(假设):识别可整体关闭;关闭时不发起识别调用,危险标记按 A8 取 true。
- Q1(待定):语义类别取哪几个 → 暂定六类:调试 / 新功能 / 重构 / 解释 / 运维 / 闲聊
- Q2(待定):识别超时阈值 → 暂定 1500ms
- Q3(待定):返回不合规结构时是否重试一次 → 暂定不重试
- Q4(待定):识别 token 在状态栏单独显示还是合并 → 暂定单独一栏
- Q5(待定):危险原因是否需要结构化(动作 + 目标)→ 暂定纯文字一句话

## 功能需求

- F1: 识别模型配置。新增一节独立识别模型条目,含端点、密钥、模型名、超时、开关;
  密钥支持环境变量回退;缺失或非法时给出清晰的启动期错误。

- F2: 联合识别调用。以当前输入 + 最近 3 轮历史为上下文,向识别模型发起一次
  非流式请求,要求按约定结构同时给出语义类别、允许工具集合、建议上下文路径、
  危险标记、危险原因五项。

- F3: 危险操作捕获。识别提示词需覆盖显式危险表述(删除、清空、覆盖、重置、
  drop、rm -rf 等)与等价的温和表述(清理一下、重来、恢复初始状态等),
  两类都应产出危险标记。

- F4: 结构校验。校验字段齐全、类型正确、语义类别为合法枚举值、工具名在已注册
  工具范围内;任一项不符视为识别无效。

- F5: 识别目标结构。产出结构含:语义类别、允许工具集合、建议上下文路径列表、
  危险标记、危险原因、识别耗时、是否降级、降级原因。

- F6: 降级路径。识别失败、超时或结构不符时不重试,产出降级识别目标:
  危险标记取 true、工具集合取只读子集、标注降级原因。

- F7: 交付调用方。识别目标以约定结构交付给调用方,调用方如何使用不在本模块范围。

- F8: 终端呈现。识别完成后在对话区显示一行摘要,含语义类别、耗时;危险标记为真时
  以可区分样式显示并附危险原因;降级时标注降级原因。

- F9: 用量统计。识别模型 token 用量与主对话分开计量,均可见。

- F10: 开关。配置可整体关闭识别;关闭时不发起调用、不显示摘要。

## 非功能需求

- N1: 识别延迟不超过超时阈值;超时立即降级。
- N2: 识别侧任何异常不影响主请求发起。
- N3: 识别期间界面保持响应,可中断;中断时不发起主请求。
- N4: 识别请求不携带主 provider 密钥;两侧密钥均不回显、不入摘要与日志。
- N5: 识别端点不可用时系统整体仍可用,连续多轮以降级目标正常完成。

## 失败模式

- E1: 识别端点不可达 → 降级,摘要标注"识别不可用"。
- E2: 识别超时 → 降级,摘要标注"识别超时"。
- E3: 返回非 JSON 或字段缺失/类型错误 → 降级,摘要标注"识别结果无效"。
- E4: 语义类别不在枚举内 → 视为无效,降级。
- E5: 工具名不在已注册范围 → 剔除未知项;剩余为空则降级。
- E6: 危险标记为真但原因为空 → 补默认原因文字,不判为无效。
- E7: 识别期间用户中断 → 抛出中断错误,不返回降级目标,由调用方处理。
- E8: 识别模型鉴权失败 → 降级并在摘要标注,不打印密钥。

## 不做的事

- 危险操作的实际拦截与确认交互:本模块只产出标记,确认由主 agent 负责。
- 主 agent 侧的任何改动:识别目标如何被消费不在本期范围。
- 复杂任务的多步联合识别与任务分解。
- 四维拆成四次独立调用。
- 识别失败后的重试与退避。
- 多语义类别并存。
- 会话级意图追踪与跨轮纠偏。
- 意图纠正反馈闭环:不收集错判样本、不做在线学习。
- 自定义语义类别与阈值:本期硬编码。
- 识别结果缓存与相似输入去重。
- 流式识别与输入过程中的实时预测。
- 识别侧多 provider 选择。
- 识别质量统计与可视化。
- 跨会话意图偏好学习。

## 验收标准

- AC1: (F1) 识别模型配置缺字段或端点非法时,启动期打印清晰错误并非零退出;
  密钥缺失时回退环境变量;任何界面区域不出现密钥。
- AC2: (F2) 提交"把 X 模块重构一遍",观察到一次识别调用发生在主请求之前,
  返回五项字段齐全。
- AC3: (F3) 显式危险样本各跑一次(删除目录、清空数据库、rm -rf、覆盖配置文件),
  危险标记均为 true 且原因文字指向具体对象。
- AC4: (F3) 温和表述的危险样本各跑一次("帮我清理一下没用的文件"、
  "把环境恢复到初始状态"、"这个模块不要了"),危险标记均为 true。
- AC5: (F3) 非危险样本各跑一次(解释函数、加一个字段、查一处调用),
  危险标记均为 false,不产生误报。
- AC6: (F4) 桩端点返回非 JSON、缺字段、类型错误、非法语义类别、含未注册工具名
  五种响应,前四种判为无效并降级,第五种剔除未知工具后继续。
- AC7: (F5) 打印识别目标,八个字段全部存在且类型正确。
- AC8: (F6) 桩端点模拟不可达、超时 2000ms、结构不符三种情况,各自产出降级目标,
  危险标记为 true、工具集合为只读子集、注降级原因,对话继续。
- AC9: (F7) 识别目标被完整交付给调用方,八个字段可在调用方侧断言可见。
- AC10: (F8) 危险、非危险、降级三种情况各跑一次,摘要样式可区分,含耗时数值。
- AC11: (F9) 一轮对话后识别 token 与主对话 token 分别可见。
- AC12: (F10) 关闭识别后提交输入,无识别调用、无摘要行。
- AC13: (N1) 桩端点延迟 2000ms 时在阈值处降级,总耗时增量不超过阈值 + 100ms。
- AC14: (N3) 识别期间中断,抛出中断错误而非降级目标,可继续下一轮。
- AC15: (N5) 识别端点全程不可达时,连续三轮对话均以降级目标正常完成。
