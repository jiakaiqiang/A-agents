## MCP 模块源码讲解（Q&A）
- 梳理了 `src/mcp/` 的收发链路：`JsonRpcConnection.send()` 只发字节，接收靠构造时注册的 `transport.onMessage(cb)` 回调 → `handleMessage()` 按 JSON-RPC id 配对 pending 表 resolve/reject。
- 讲清 stdio 双管道：`send` 写 `child.stdin`，server 处理后把响应写 `child.stdout`，client 由 `consumeStdout` 按行分帧回调。接收到的永远是处理后的响应而非回声。
- 讲清三层原理：TS interface 编译擦除（`McpTransport` 只是合同）→ 运行时原型链找到 `StdioTransport.prototype.send` → Node 把管道写端 fd 封装成 Writable 流 → `write()` 系统调用写内核匿名管道缓冲区。
- 工具加载现状：`main.tsx:58` `connectAll` 并行连所有 server，每个 server 握手后 `tools/list` 一次性全量注册进 registry；每轮对话 `definitionsFor()` 全量下发 LLM；无按需机制。

## 延迟加载方案（已给方案，未实现）
用户需求：初始化只拿工具总数/目录，部分工具延迟加载；未加载工具后续使用时从维护的 system-reminder 中获取再执行。
方案要点（关键约束：LLM 只能调用当次请求 tools 数组里出现过的工具，reminder 只能做目录+指引，不能替代注册）：
1. `LazyToolIndex`：启动时 `tools/list` 后不注册，只存全量目录（name → server + 完整 McpToolDef）。
2. `ToolRegistry` 扩展：`registerLazy(def, loader)` / `ensureLoaded(name)`，另维护 lazy 目录防重名。
3. 每轮 reminder 由 Index 生成目录清单（可用 X 个 / 延迟 Y 个 + 名字与一句话描述），走既有 `wrapReminder` → `reminders` 管线（`prompt/reminder.ts`、`loop.ts:113` 每次迭代都挂）。
4. 回补路径：`runTool`（`tools/execute.ts:30`）get 未命中 → 查 Index → 命中则 `createMcpTool` 包装真注册 → 当次即可执行；未命中维持 `fail("unknown_tool")`，`invalidStreak` 兜底。
5. 加载后追加一条 reminder 告知模型该工具已可用（下一轮 schema 自动出现在 tools 数组）。
若实现，改动点：types.ts / manager.ts / registry.ts / execute.ts / reminder.ts / loop.ts。

## toolSearch 延迟加载方案 v2（用户主导设计，已确认方案未实现）
用户明确设计：MCP 工具注册时全标延迟；每轮 tools 数组只含内置 + toolSearch 元工具 + 已发现工具；system-reminder 只列延迟工具名字目录；模型调 toolSearch(query) → 查 lazy 池 → registry.discover() 翻转为已发现 → 下一轮 schema 进 tools 数组。
关键适配点：
- `loop.ts:111` definitionsFor 在 while 内每次迭代重建 tools——发现后下一轮自动出现，结构不用改。
- `loop.ts:74` reminders 在循环外算一次，目录动态变化需移入循环或增量合并。
- `createDefaultRegistry()`（tools/index.ts:21）固定注册六内置工具，toolSearch 元工具在此追加。
- 安全网：模型可能跳过 toolSearch 直接调未加载工具（训练习性），`runTool` 的 unknown_tool 分支（execute.ts:31）改为查 lazy 池自动补载：参数过 schema 校验直接执行，否则回传 schema 要求重发。
- 缓存注意：tools 数组变化会使提示词缓存前缀失效一次，之后新前缀稳定命中。
- 新文件建议 mcp/lazy.ts 放 LazyToolIndex；registry 扩展 registerLazy/discover/listLazy；toolSearch 本身是普通 Tool（readOnly: true）走既有管线。
- 与用户约定：本轮只出方案不实现。
